# E-Commerce Sales Analysis 📊

## Project Overview

This project analyzes e-commerce sales data using Python and Pandas to identify sales trends, customer purchasing patterns, and business insights.

## Tools & Technologies

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook

## Analysis Performed

- Dataset exploration
- Data cleaning and validation
- Sales statistics
- Revenue by category
- Revenue by region
- Product sales analysis
- Monthly revenue trends
- Payment method analysis
- Discount analysis
- Business insights

## Key Insights

- Top-selling product: Laptop
- Highest revenue category: Electronics
- Highest revenue region: West
- Best revenue month: November 2025
- Most-used payment method: UPI
- Average discount: 4%
