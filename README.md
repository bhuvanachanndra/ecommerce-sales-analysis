# Customer Churn Analysis

## Project Overview
This project analyzes customer churn data using Python and Pandas.

## Objectives
- Analyze customer churn percentage
- Study customer tenure
- Analyze monthly charges
- Understand factors related to customer churn
- Generate useful insights from the dataset

## Technologies Used
- Python
- Pandas
- NumPy
- Jupyter Notebook
- Git & GitHub
